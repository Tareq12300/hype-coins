# Coin Sonar Bot — الإصدار الأول

بوت تيليجرام لمراقبة الارتفاعات المفاجئة في أزواج USDT الفورية على:

- Binance
- Gate
- MEXC
- KuCoin

كل منصة تعمل بشكل مستقل، ويكفي تحقق الشروط في منصة واحدة لإرسال التنبيه.

## ما الذي يفحصه؟

1. ارتفاع السعر خلال آخر دقيقة.
2. حجم تداول آخر دقيقة بالـ USDT.
3. نسبة عمليات الشراء من التداولات المنفذة.
4. حجم تداول 24 ساعة.
5. تغير السعر خلال 24 ساعة.
6. فترة منع تكرار التنبيه وعدد التنبيهات في الساعة.

> تحليل تغير السيولة المتقدم، CVD، الحيتان، ودفتر الأوامر مؤجلة للإصدار الثاني.

## التشغيل على Railway

1. فك ضغط الملف وارفع المجلد إلى GitHub.
2. أنشئ مشروعًا جديدًا في Railway من المستودع.
3. افتح Variables وأضف القيم الموجودة في `.env.example`.
4. ضع `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID`.
5. ابدأ النشر.

لا تحتاج مفاتيح API للمنصات لأن البوت يستخدم بيانات السوق العامة فقط.

## معرف تيليجرام

- للمحادثة الخاصة: أرسل رسالة للبوت ثم استخدم بوتًا موثوقًا لمعرفة Chat ID.
- للقناة: أضف البوت مشرفًا، واستخدم `@channelusername` في `TELEGRAM_CHAT_ID` إن كانت القناة عامة.
- للقناة الخاصة: استخدم المعرف الرقمي الذي يبدأ غالبًا بـ `-100`.

## ملاحظات مهمة

- أول تنبيه لا يمكن أن يظهر قبل مرور دقيقة تقريبًا، لأن البوت يحتاج إلى بناء سجل للسعر.
- بعض المنصات قد لا تعيد كل صفقات الدقيقة إذا كانت العملة شديدة النشاط؛ يمكن رفع `FETCH_TRADES_LIMIT` ضمن حدود المنصة.
- `fetch_tickers` قد يكون أثقل على بعض المنصات، لذلك لا تجعل `POLL_SECONDS` منخفضًا جدًا. القيمة المقترحة 15 ثانية.
- هذا البوت للتنبيه والتحليل وليس توصية شراء أو ضمانًا للربح.

## تجربة محلية

```bash
cp .env.example .env
pip install -r requirements.txt
python bot.py
```
